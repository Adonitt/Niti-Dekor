# Niti Dekor website

React + Vite website for Niti Dekor in Prishtinë.

## Start locally

npm install
npm run dev

## Build

npm run build

## Request form

The form creates a WhatsApp message containing the visitor's project details. The visitor reviews and sends the message in WhatsApp. The website does not store submissions.

## Before making the site public

- Replace the clearly labelled illustrative photos with real Niti Dekor project photos.
- Confirm that both phone numbers are active on WhatsApp.
- Confirm exact nearby municipalities and any service-specific commitments.
- Review service descriptions, measurement arrangements, and pricing factors with the business owner.
